# COSMETIC-BRAND-E-COMMERCE-SALES-DATASET-ANALYSIS

## 📖 Project Overview

This project focuses on analyzing online cosmetic sales in India. The dataset provides insights into customer demand, product performance, and regional sales trends, enabling strategic decision-making for a cosmetic brand serving diverse regions and skin tones.

## 🎯 Project Objectives

- Understand customer purchasing behavior
- Identify top-performing products and variants
- Analyze regional and city-level sales contributions
- Explore sales trends over time
- Provide actionable recommendations for marketing, inventory, and pricing strategies

## 📂 Dataset
- Records: 8,165
- Attributes: 18 features

## 🛠️ Tools Used
- Language: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn, Plotly

## 🧹 Data Cleaning and Preprocessing
- Steps performed:
    - Handling missing values
    - Checking and removing duplicates
    - Correcting datatypes for consistency
    - Calculating Sales and Average Order Value (AOV) for smooth analysis
  
## 📊 Exploratory Data Analysis (EDA)
For visualization, the following techniques were used:
- Histogram
- Line chart
- Boxplot
- Heatmap

## 🔍 Key Insights
- Unique customers: 2012, with 76% repeat buyers → strong loyalty base
- Order status: 5,788 delivered (high satisfaction), 2,329 in transit (needs monitoring)
- Order size: Majority prefer single-item purchases
- Top product: Insight Glitter Purse (highest AOV ₹800)
- Regional leader: Datia city dominates sales; West Zone shows highest average spend
- Time trend: October peak sales (festive season), sharp drop in November
- Product variants: Prime It Up most popular across all skin tones; Mini Power Matte Lipcolour highly repeated

## ✅ Recommendations
- Launch loyalty programs and personalized offers to convert one-time buyers.
- Strengthen courier partnerships and enable real-time tracking to reduce delays.
- Expand beyond Datia and grow secondary cities/zones to reduce dependency.
- Build campaigns around hero products (Prime It Up, Mini Power Matte Lipcolour) to boost AOV.
- Design festive and off-season promotional calendars to sustain demand.
- Prioritize inventory in Maharashtra; strengthen campaigns in West Bengal, Delhi, Karnataka, and Uttar Pradesh.
- Selectively increase prices on high-demand products/variants to improve margins without hurting sales.
